# Source Preservation

The purpose of this repository is to organize and document the uploaded work without rewriting it.

## Preserved artifacts

Every file listed in `ORIGINAL_FILE_MANIFEST.tsv` was copied directly from the uploaded archive. The manifest records:

- original archive path;
- portfolio path;
- file size;
- SHA-256 hash of the original;
- SHA-256 hash of the portfolio copy; and
- whether the two files are byte-identical.

## Permitted additions

The following files were newly created around the preserved work:

- root and project README files;
- `.gitignore`;
- `requirements.txt`;
- verification and exclusion notes;
- preview PNGs extracted from image outputs already embedded in two notebooks.

The preview PNGs are derivative convenience files and are not represented as original submissions.

## No silent code changes

No cells, comments, outputs, metadata, calculations, or report pages inside the preserved artifacts were changed. Suggested improvements belong in documentation and were not applied to the original work.
