# 3D Flat Shading and Vertex Normals

This notebook applies vector geometry to an icosahedron stored in Wavefront OBJ format.

![Recorded notebook output](preview/notebook-output.png)

## What the notebook implements

- view-direction calculation from azimuth and elevation;
- triangle face normals using cross products;
- face-visibility testing using a dot product;
- reflection-based intensity calculation;
- OBJ vertex and face parsing;
- model centering and uniform scaling;
- moving-light animation;
- vertex-normal estimation by averaging adjacent normalized face normals.

## Linear-algebra connection

The rendering calculations rely on normalized vectors, cross products, and dot products:

- cross products construct a normal perpendicular to a triangular face;
- dot products determine orientation and lighting alignment;
- sums of adjacent face normals produce per-vertex normals before normalization.
